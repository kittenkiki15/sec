# ADR-0008: 数式中の `A1` は Cell に評価され、理解できないメッセージは値へ委譲する

- 状態: accepted
- 日付: 2026-09-14
- 関連: [ADR-0007](0007-range-cell-reference-assignment.md)

## 背景

ADR-0007 は範囲の正準形を `A1 to: B10` と定め、「`Cell>>to:` が `Range` を返す」と書いた。
これは `A1` が `Cell` オブジェクトに評価されることを示唆するが、**`A1 + 1` が何を意味するかを
定めていなかった。** 段階 2（#4）で §4 を書くには、これを先に決める必要がある。

## 選択肢

| 案 | 内容 | 欠点 |
| --- | --- | --- |
| A | `A1` は `Cell`。`Cell` が理解しないメッセージは保持する値へ転送する | 委譲という機構がやや魔法的 |
| B | `A1` はセルの値そのもの。`to:` だけ「受け手がセル参照の場合」に限る特別な規則 | `Cell` クラスの存在意義が薄れ、脱糖先の `to:` が通常のメッセージ送信でなくなる |
| C | `A1` は `Cell`。委譲はしない。値を取るには `A1 value` と書く | 表計算として書き味が悪い |

## 決定

**A を採用する。**

- `A1` は `Cell` オブジェクトに評価される。
- `Cell` 自身は `to:` `value` などを理解する。
- **`Cell` が理解しないメッセージ（`+` `abs` など）は、保持する値へ転送する。**
- 値の表示は、保持する値の表記に従う（§0.3）。

これにより `A1 + 1` や `A1 abs` が自然に書ける一方、`A1 to: B10` が
通常のメッセージ送信のまま成り立つ。要件 F-2-7 が `Cell` を組み込みクラスに
挙げていることとも整合する。

## 影響

- §4（段階 2、#4）でこの意味論を書き下ろす。
- 委譲の結果、`Cell` に無いセレクタのエラーは**値が返す** `#DoesNotUnderstand` になる。
  どのオブジェクトが理解しなかったかをエラーに含めるかは、文言の問題なので本書では定めない
  （要件 F-8-3）。
- セルが空のときの委譲先は未決論点 D-6 に依存する。§6 で決める。
- セルがエラーを保持している場合、委譲の結果もそのエラーになる（要件 F-8-1 の伝播）。

## 決めていないこと

- **`A1 = A2` がセルの同一性の比較か、保持する値の比較か。**
  委譲の規則をそのまま適用すれば値の比較になるが、`=` を `Cell` 自身が理解する設計も
  ありうる。§4 で決める。
- `Cell` 自身が理解するセレクタの一覧。§4 と §6 で確定させる。

## 覆すとしたら

- 委譲によって「どのオブジェクトへのメッセージか」が利用者に分からなくなり、
  エラーメッセージで説明しきれないと判明したとき → C（明示的な `value`）に寄せる
