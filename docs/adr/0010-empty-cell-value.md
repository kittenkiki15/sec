# ADR-0010: 空セルの値は `nil` とし、集計では無視する（D-6）

- 状態: accepted
- 日付: 2026-09-14
- 関連: 要件 D-6、F-2-8、[ADR-0008](0008-cell-value-delegation.md)、仕様書 §2.5、§4.3、§6

## 背景

要件定義書の未決論点 **D-6「空セルの値。`nil` か `0` か空文字か」** が未決のまま残っていた。

§4.3 は範囲の**中身**を扱うセレクタ（`sum` など）を §6 送りにしており、その理由として
「空セルの値が未決であり、それが決まるまで集計の仕様は書けない」と書いている。
ADR-0008 も「セルが空のときの委譲先は D-6 に依存する」として保留していた。
**段階 3（#5）で §6 を書くには、これを決めなければ先へ進めない。**

## 選択肢

| 案 | 内容 | 利点 | 欠点 |
| --- | --- | --- | --- |
| A | `nil`。集計では無視する | 「値が無い」を表すオブジェクトが既にある（§2.5）。`average` が歪まない | 空セルを含む算術がエラーになる（Excel と異なる） |
| B | `0` | `=A1+B1` が Excel と同じに振る舞う | **入力漏れが 0 と区別できない。** `average` が歪む。文字列の列でも 0 になる |
| C | 空文字 `''` | 文字列の連結が自然に書ける | 数値の列で `sum` が型エラーになる。B と同じく入力漏れが隠れる |

## 決定

**A を採用する**（要件定義書が推奨案としていたもの。利用者の選択）。

- **空セルの値は `nil`。** `A1` が空なら `A1 value` は `nil` を返す
- **集計セレクタは `nil` の要素を無視する。** `sum` `average` `min` `max` `count` は
  空セルを「要素として数えない」
- **空の集計（要素が 1 つも残らない場合）の返り値**は次のとおり。
  単位元があるものだけが値を返す。

  | セレクタ | 空のときの返り値 | 理由 |
  | --- | --- | --- |
  | `sum` | `0` | 加法の単位元。Excel の `SUM` も空範囲で 0 |
  | `count` | `0` | 個数なので 0 が自然 |
  | `min` / `max` / `average` | `nil` | 単位元が無く、返せる値が存在しない |

### 空セルを含む算術はエラーのままにする

**例外を作らない。** ADR-0008 の委譲規則をそのまま適用する。

```smalltalk
"A1 が空のとき"
A1 + 1   "→ #DoesNotUnderstand。nil は + を理解しない"
1 + A1   "→ #TypeError。Number は + を理解するが、引数の型が合わない"
```

**Excel は両方 `1` を返すので、ここは意図的な乖離である。** そうした理由は 2 つ。

1. **入力漏れが黙って 0 扱いされない。** 表計算の事故の多くは「入っているはずの値が
   入っていない」ことに気付かないまま計算が通ってしまうことに起因する
2. **「すべてがメッセージ送信」という土台を崩さない。** 算術の文脈でだけ `nil` を
   `0` と読む規則を足すと、`nil + 1` を直接書いた場合の扱いも別途決めることになり、
   規則が増える

まとめて足したい場合は `A1..A10 sum` が使える。**集計は空を無視するので、
そちらは期待どおりに動く。**

## 影響

- §6 の集計セレクタの仕様をこの前提で書ける。§4.3 の保留が解消される
- ADR-0008 の「委譲先は D-6 に依存する」が解消される。空セルの委譲先は `nil`
- `tests/golden/README.md` が「空セルの意味は未決のため、内容が空の指定は
  受け付けません」としている制約は**そのまま残す。** 空セルは「指定の無いセル」で
  表せるので、空文字を書ける必要が無い
- 付録 B の D-6 が解消される

## 覆すとしたら

- 空セルを含む算術のエラーが実利用で頻発し、利用者が `A1 ifNil: [0]` を
  書き続けることになると判明したとき → 空セルだけ `0` として読む案を再検討する。
  その場合でも `nil` そのものの意味論は変えない
