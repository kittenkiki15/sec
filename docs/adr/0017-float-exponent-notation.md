# ADR-0017: 小数の指数表記は Smalltalk に寄せ、切り替えの境界は本書で固定する

- 状態: accepted
- 日付: 2026-09-15
- 関連: [ADR-0012](0012-number-model.md)、[ADR-0013](0013-non-finite-numbers.md)、仕様書 §0.3、§2.1、§6.1

## 背景

§0.3 は小数の表記を「通常表記では小数点を必ず付ける」とだけ定め、**`1e-310` のように
通常表記では極端に長くなる値をどう書くかを付録 B に送っていた。** 決めるのは 3 点である。

1. 指数表記を使うか
2. 使うなら仮数をどう書くか（`1.0e-310` か `1e-310` か）
3. 通常表記との境界をどこに置くか

利用者の指示は「**Smalltalk か Excel のどちらかの仕様に寄せたい**」であった。

## Excel は選べない

**Excel の指数表記は大文字 `E` と明示的な符号を使う**（`1.23E+15`）。

ところが **§2.1 は大文字の `E` を拒んでいる。** `1E3` の `E3` がセル参照の形（§1.2）と
衝突するためで、段階 1 で確定した判断である。Excel 流にすると次の 2 つが壊れる。

- **出力した値をリテラルとして読み戻せなくなる**
- §6.2 が `asNumber` の受理する形を「**§2.1 の数値リテラルちょうど**」と定めた根拠が崩れる

**したがって Smalltalk に寄せる。**

## 決定

### 1〜2 は Smalltalk に寄せる

- **指数表記を使う**
- **指数は小文字 `e`。正の指数に `+` は付けない**（`1.0e21`）
- **仮数は最短往復表記の桁で、小数点を必ず含む**（`1.0e-310`）

仮数に小数点を付けるのは、§0.3 の「小数は小数点を必ず付ける」をそのまま延長したものであり、
**表記だけで整数と小数を見分けられる**状態を保つ。`1e-310` と書くと、§2.1 では同じ形が
整数リテラルの綴りでもあるため、表記から型が読めなくなる。

### 3 の境界は本書で固定する。ここは「Smalltalk に寄せた」とは言わない

**Smalltalk の実装でも切り替えの境界は分かれる。** 寄せる先が一意に決まらないので、
本書で一点に固定する。

> **指数表記を使うのは、値が 0 でなく、絶対値が `1e21` 以上、または `1e-6` 未満のとき。
> それ以外は通常表記。**

**この数値に理論的な必然性は無い。** 一意に定めることだけが目的である。次を確認したうえで
選んだ。

- §0.3 が例に挙げている `1500.0` が通常表記のまま残る
- `0.000001`（`1e-6`）は通常表記、`1e-7` から指数表記に移る
- 既存のゴールデンテストの期待値（`0.30000000000000004`、`9007199254740992.0`、
  `2.3333333333333335`）がすべて通常表記のまま変わらない

## 影響

- §0.3 の値の表記から「指数表記は未決」の注記を外す
- 付録 B から「極端な大きさの小数の表記」を外す
- **M0 の範囲で、値の表記に未決が無くなる**
- 評価器は、この境界で通常表記と指数表記を切り替える

## 覆すとしたら

- 境界の値が実利用で不便と分かったとき → 境界だけを動かす。仮数と指数の形（1〜2）は
  §2.1 との整合に縛られているので動かせない
