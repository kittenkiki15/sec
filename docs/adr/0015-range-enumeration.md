# ADR-0015: 範囲の列挙は `Cell` を渡し、行優先で進む

- 状態: accepted
- 日付: 2026-09-15
- 関連: [ADR-0008](0008-cell-value-delegation.md)、[ADR-0010](0010-empty-cell-value.md)、仕様書 §4.3、§6.3

## 背景

§6.3 で `collect:` などを定めるにあたり、**`A1..A3 collect: [:x | x * 2]` のブロックに
何が渡るか**を決める必要があった。`Cell`（ADR-0008）か、保持する値かである。

ADR-0010 は「**集計セレクタは `nil` の要素を無視する**」と定めたが、**列挙が無視するかは
定めていなかった。**

## 選択肢

| 案 | 内容 | 利点 | 欠点 |
| --- | --- | --- | --- |
| A | **`Cell` を渡す** | ブロックの中でセル自身を扱える。§4.2 の規則 2 が働くので `[:c \| c * 2]` はそのまま書ける | `[:c \| c]` が `Cell` の配列を返し、表記の上では値の配列と見分けが付かない |
| B | 値を渡す。空セルは `nil` のまま | 配列と範囲で列挙の要素が揃う | セル自身に触れる手段が列挙から失われる |

## 決定

**A を採用する**（利用者の選択）。

- **範囲の列挙（`collect:` `select:` `reject:` `detect:ifNone:` `inject:into:` `sorted:`）は
  `Cell` を渡す**
- **配列の列挙は値を渡す。** リテラル配列の要素はそもそもセルではない
- **列挙は `nil` を無視しない。** 無視するのは集計（`sum` `count` `min` `max` `average`）だけ

### 配列と範囲で非対称になる

**この非対称は意図的である。** 範囲はセルの矩形であり、配列は値の並びなので、
要素の正体が違う。

```smalltalk
#(1 2 3) collect: [:x | x]      "→ 値の配列"
A1..A3 collect: [:c | c]        "→ Cell の配列"
```

**表記の上では区別が付かない。** §0.3 がセルの表記を「保持する値の表記に従う」と
定めているためで、どちらも `#(1 2 3)` と表示される。**`value` を送れるかどうかが
唯一の見分け方**であり、ゴールデンテストではそれで固定する。

```smalltalk
A1..A3 first value        "→ 1。Cell なので value を理解する"
#(1 2 3) first value      "→ #DoesNotUnderstand。値は value を理解しない"
```

### 空セルは列挙に現れる

集計と違い、**列挙では空セルが `nil` を保持する `Cell` として渡る。**

```smalltalk
"A2 が空のとき"
A1..A3 collect: [:c | c value]        "→ #(1 nil 3)"
A1..A3 collect: [:c | c * 2]          "→ #DoesNotUnderstand。nil は * を理解しない"
A1..A3 collect: [:c | c ifNil: [0]]   "→ #(1 0 3)"
```

2 つめがエラーになるのは ADR-0010（空セルを含む算術はエラー）の帰結であり、
**列挙でだけ空を飛ばす特別扱いは作らない。** 飛ばすと要素数が変わり、`select:` との
区別が付かなくなる。

### 列挙は行優先

**左から右へ進み、行が尽きたら次の行へ移る。**

```smalltalk
"A1=1, B1=2, A2=3, B2=4 のとき"
A1..B2 collect: [:c | c value]   "→ #(1 2 3 4)"
```

読み順であり、Excel の配列数式の並び順とも揃う。

## 影響

- §6.3 に `Array` と `Range` の列挙を別々に書く
- `Range` の `first` / `last` / `at:` も `Cell` を返す
- 評価器は、範囲の列挙でセルを生成し、配列の列挙では値をそのまま渡す

## 覆すとしたら

- `Cell` が配列に混ざることで、後続の処理が値を期待して壊れる事故が頻発したとき
  → B（値を渡す）へ。その場合 `A1..A3 collect: [:c | c]` の期待値は変わらないが、
  `value` を送るケースがすべて `#DoesNotUnderstand` になる
