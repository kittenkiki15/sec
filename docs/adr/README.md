# 設計判断の記録（ADR）

1 件の判断を 1 ファイルに記録する。`NNNN-短い題名.md` の形式で連番を振る。

**目的は「決め直しを防ぐこと」。** セッションをまたぐと Claude Code の文脈は消えるため、
判断の理由がリポジトリに残っていないと、次のセッションで同じ議論が蒸し返される。

## 書くもの

- 言語の構文・意味論の選択（範囲リテラルの記法、セル参照の扱いなど）
- アーキテクチャの分割方針、依存の向き
- 技術選定
- 一度採って後から覆した判断（古い ADR は消さず、`status` を `superseded` にして
  後継 ADR へのリンクを書く）

## 書かないもの

- 実装の詳細。コードとコメントで足りる
- 明日には忘れてよい一時的な判断

## テンプレート

`docs/adr/0000-template.md` をコピーして使う。
