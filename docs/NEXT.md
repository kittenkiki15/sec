### 段階 3（PR A）で確定させた判断（レビュー対象）

ADR にしたものが 4 件（0010 / 0011 / 0012 / 0013）。**PR A は AI レビューを 11 回受け、
10 件の指摘に対応した**（3 件が初版から残っていた仕様の穴、5 件が自分の修正の副作用、
2 件がメタ情報の書き漏らし）。0013 はその 1 回目への対応で、
**要件定義書 F-8-2 のエラー種別を 7 種から 8 種に増やしている**（`#Overflow` を追加）。
非有限値（`Infinity` `NaN`）を値として持たないという判断で、`rounded` / `truncated` が
常に整数を返す規則を保つため。

ADR にせず付録 A に入れたものは次のとおり。

- **負の数の `sqrt` は `#Overflow`。** 数の範囲・定義域の誤りを 1 つの種別にまとめた（ADR-0013）
- **`2.5 rounded` は `3`**（大きい側へ）。Smalltalk-80 の `rounded` に合わせた
- **`3 between: 5 and: 1` は `false`。** 範囲（§4.3）と違い区間は正規化しない
- **`=` `~=` は型が違ってもエラーにしない**
- **`Date` / `Sheet` は §6 に入れない。** F-2-7 は挙げているが、日付は F-2-12（優先度 S）で
  決定性の設計が別途要り、`Sheet` は数式から触れると副作用の経路になる（F-2-10）
- **アンダーフローは `0.0` に丸める**（エラーにしない）。下側には丸め先があり上側には無い
- **`min:` / `max:` は `<` `>` で定義し、同値なら引数を返す**（`1 min: 1.0` → `1.0`）
- **負のゼロは値としては残すが表記は `0.0`**

### 段階 3 で先送りした論点

**極端な大きさの小数の表記**を付録 B へ送った。決めるのは 3 点 ——
(1) `1e-310` のような値に指数表記を使うか、(2) 使うなら仮数に小数点を付けるか、
(3) 通常表記との境界をどこに置くか。**§0.3 の「小数点を必ず付ける」は通常表記に限る**
と明記して矛盾を解いてある。ゴールデンテストに指数表記の期待値は 1 件も無いので、
この未決は今のところ何も妨げていない。**PR B か C で決めること。**

### 段階 2 で確定させた判断（レビュー対象）

仕様書の付録 A に一覧がある。特に次の 3 つは覆すなら ADR が要る。

- **`A1 = A2` は値の比較。** `Cell` は `=` を定義せず、ADR-0008 の委譲規則に任せる
- **範囲の表記は正準形と同じ `A1 to: B10`。** 糖衣の設定で読み方が揺れないようにするため
- **逆向きの範囲は正規化する。** `B10 to: A1` は `A1 to: B10` と同じ矩形

**数式のブロックの本体は式ちょうど 1 つ**とした（F-2-10）。文の列と一時変数を持つ
ブロックは段階 4（#6）でマクロの文法として扱う。

### 段階 1 で確定させた判断（レビュー対象）

仕様書 `docs/02-language-spec.md` の付録 A に一覧がある。特に次の 3 つは覆すなら ADR が要る。

- **指数の `e` は小文字だけ。** `1E3` は `E3` がセル参照の形と衝突するため `#Syntax`
- **`5.` は小数として認めない。** マクロの文区切り `.` と紛れるため
- **負のリテラルと二項の `-` は直前のトークンで区別する。** `3 -4` は `-1`

段階 1〜2 のフィクスチャが先に使ってしまったセレクタのうち、**`abs` / `negated` / `squared` /
`max:` / `min:` / `between:and:` / `/` / `>` は §6.1 に入れた。** 残るは `size`（§6.2 の
`String`、PR B）と `sum`（§6.3 の `Range`、PR C）。**PR C でセレクタの網羅を機械的に検査する
テストを入れる**予定（仕様書の表に無いセレクタがフィクスチャに現れたら落とす）。
