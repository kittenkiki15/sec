"言語仕様書 §4（セル参照）に対応するゴールデンテスト。
"範囲そのものは ranges.txt に分けてある。
"
"セルの状態は `!A1 := 1` の形で式より前に書く（ADR-0009）。
"空セルの値は nil（ADR-0010、D-6 の決定）。空セルを含む算術は errors.txt にある。

"--- セル参照が返すもの ---

"セル参照は Cell に評価され、表記は保持する値に従う（ADR-0008）
!A1 := 1
A1
=> 1

!A1 := 3.14
A1
=> 3.14

!A1 := 'abc'
A1
=> 'abc'

!A1 := true
A1
=> true

"Cell 自身が value を理解する
!A1 := 1
A1 value
=> 1

"指定の無いセルは空で、値は nil（ADR-0010、D-6 の決定）
A1
=> nil

A1 value
=> nil

"--- セルの内容の読み方（§4.4、ADR-0021） ---

"内容がリテラルちょうど 1 つとして読めればその値（段 2）。正規化は §2.1 に従う
!A1 := 007
A1
=> 7

!A1 := #foo
A1
=> #foo

!A1 := #(1 2 3)
A1
=> #(1 2 3)

!A1 := -5
A1
=> -5

"リテラルとして読めても値がエラーになることがある（ADR-0013）。文字列にはならない
!A1 := 1.0e400
A1
=> #Overflow

"リテラルとして読めない内容はそのままの文字列（段 3）
!A1 := abc
A1
=> 'abc'

"セル参照はリテラルではない（§2）ので、内容としては文字列になる
!A1 := B1
A1
=> 'B1'

"リテラルが 1 つでなければ文字列。式ではない
!A1 := 1 + 2
A1
=> '1 + 2'

"= が途中にあっても数式にならない（段 1 は 1 文字目だけを見る）
!A1 := 1 = 2
A1
=> '1 = 2'

"--- 値への委譲 ---

"Cell が理解しないメッセージは保持する値へ転送される（ADR-0008）
!A1 := 3
A1 + 1
=> 4

!A1 := -5
A1 abs
=> 5

!A1 := 3
!B1 := 4
A1 + B1
=> 7

"引数の側だけがセルでも、値に解決されてから送られる
!A1 := 3
1 + A1
=> 4

"受け手も引数もセルでない位置は影響を受けない
!A1 := 3
1 + 2
=> 3

"Cell 自身が理解するセレクタでは、引数はセルのまま渡る（§4.3 の to:）
!A1 := 1
!B2 := 2
A1 to: B2
=> A1 to: B2

"委譲の結果も通常の優先順位に従う（§3.5）
!A1 := 3
!B1 := 4
A1 + B1 * 2
=> 14

"受け手が数でなくても委譲は同じように働く
!A1 := 'abc'
A1 size
=> 3

"--- 等値比較 ---

"Cell は = を定義しない。委譲の規則がそのまま働き、値の比較になる
!A1 := 1
!A2 := 1
A1 = A2
=> true

!A1 := 1
!A2 := 2
A1 = A2
=> false

"セルとリテラルの比較も値で行われる
!A1 := 1
A1 = 1
=> true

"別のセルを指していても、値が等しければ true
!A1 := 'abc'
!B7 := 'abc'
A1 = B7
=> true

"--- 数式を持つセル ---

!pending m3
!A1 := 1
!B1 := =A1 + 1
B1
=> 2

"数式は他の数式セルを参照できる
!pending m3
!A1 := 1
!B1 := =A1 + 1
!C1 := =B1 * 10
C1
=> 20

"--- 循環参照 ---

"自分自身を参照する数式
!pending m3
!A1 := =A1
A1
=> #Circular

"2 つのセルが互いを参照する
!pending m3
!A1 := =B1
!B1 := =A1
A1
=> #Circular

"--- セル参照の形 ---

"列は複数文字でもよい
!AB12 := 7
AB12
=> 7

"行の桁数に制限は無い
!A100 := 7
A100
=> 7

"--- 番地の正規化（§4.1、ADR-0020） ---

"行の前ゼロは番地に残らない。A007 と A7 は同じ 1 つのセル
!A7 := 1
A007
=> 1

"指定の側に前ゼロがあっても同じセルを指す
!A007 := 1
A7
=> 1

"--- 存在しない参照 ---

"行は 1 始まり（要件 F-1-3）。行 0 は存在しない
A0
=> #Ref

"正規化した結果が 0 なら解決できない（ADR-0020）
A000
=> #Ref

"--- 識別子 ---

"数式中の裸の識別子は解決できない。名前付き範囲（F-1-8）は MVP の範囲外
total
=> #Ref

"セル参照の形でない大文字混じりの名前も識別子であり、同じく解決できない（§1.2）
Abc123
=> #Ref
