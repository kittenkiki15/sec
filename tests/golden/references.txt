"言語仕様書 §4（セル参照）に対応するゴールデンテスト。
"範囲そのものは ranges.txt に分けてある。
"
"セルの状態は `!A1 := 1` の形で式より前に書く（ADR-0009）。
"空セルの値は nil（ADR-0010、D-6 の決定）。空セルを含む算術は errors.txt にある。

"--- セル参照が返すもの ---

"セル参照は Cell に評価され、表記は保持する値に従う（ADR-0008）
!pending m3
!A1 := 1
A1
=> 1

!pending m3
!A1 := 3.14
A1
=> 3.14

!pending m3
!A1 := 'abc'
A1
=> 'abc'

!pending m3
!A1 := true
A1
=> true

"Cell 自身が value を理解する
!pending m3
!A1 := 1
A1 value
=> 1

"指定の無いセルは空で、値は nil（ADR-0010、D-6 の決定）
!pending m3
A1
=> nil

!pending m3
A1 value
=> nil

"--- 値への委譲 ---

"Cell が理解しないメッセージは保持する値へ転送される（ADR-0008）
!pending m3
!A1 := 3
A1 + 1
=> 4

!pending m3
!A1 := -5
A1 abs
=> 5

!pending m3
!A1 := 3
!B1 := 4
A1 + B1
=> 7

"引数の側だけがセルでも、値に解決されてから送られる
!pending m3
!A1 := 3
1 + A1
=> 4

"受け手も引数もセルでない位置は影響を受けない
!pending m3
!A1 := 3
1 + 2
=> 3

"Cell 自身が理解するセレクタでは、引数はセルのまま渡る（§4.3 の to:）
!pending m3
!A1 := 1
!B2 := 2
A1 to: B2
=> A1 to: B2

"委譲の結果も通常の優先順位に従う（§3.5）
!pending m3
!A1 := 3
!B1 := 4
A1 + B1 * 2
=> 14

"受け手が数でなくても委譲は同じように働く
!pending m3
!A1 := 'abc'
A1 size
=> 3

"--- 等値比較 ---

"Cell は = を定義しない。委譲の規則がそのまま働き、値の比較になる
!pending m3
!A1 := 1
!A2 := 1
A1 = A2
=> true

!pending m3
!A1 := 1
!A2 := 2
A1 = A2
=> false

"セルとリテラルの比較も値で行われる
!pending m3
!A1 := 1
A1 = 1
=> true

"別のセルを指していても、値が等しければ true
!pending m3
!A1 := 'abc'
!B7 := 'abc'
A1 = B7
=> true

"--- 数式を持つセル ---

!pending m3
!A1 := 1
!B1 := =A1 + 1
B1
=> 2

"数式は他の数式セルを参照できる
!pending m3
!A1 := 1
!B1 := =A1 + 1
!C1 := =B1 * 10
C1
=> 20

"--- 循環参照 ---

"自分自身を参照する数式
!pending m3
!A1 := =A1
A1
=> #Circular

"2 つのセルが互いを参照する
!pending m3
!A1 := =B1
!B1 := =A1
A1
=> #Circular

"--- セル参照の形 ---

"列は複数文字でもよい
!pending m3
!AB12 := 7
AB12
=> 7

"行の桁数に制限は無い
!pending m3
!A100 := 7
A100
=> 7

"--- 存在しない参照 ---

"行は 1 始まり（要件 F-1-3）。行 0 は存在しない
!pending m3
A0
=> #Ref

"--- 識別子 ---

"数式中の裸の識別子は解決できない。名前付き範囲（F-1-8）は MVP の範囲外
!pending m3
total
=> #Ref

"セル参照の形でない大文字混じりの名前も識別子であり、同じく解決できない（§1.2）
!pending m3
Abc123
=> #Ref
