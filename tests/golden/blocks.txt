"言語仕様書 §5（ブロック）に対応するゴールデンテスト。
"条件式は conditionals.txt に分けてある。
"
"ここにあるのは数式の中のブロック。マクロのブロック（文の列を含むもの）は §7 で扱う。

"--- 引数を取らないブロック ---

"ブロックは value で評価する
[3 + 4] value
=> 7

"評価するまで中身は評価されない。これが遅延評価の土台（要件 F-2-9）
[1 / 0] value
=> #DivideByZero

"ブロックそのものは値である。表記は aBlock で、引数の数も本体も表記しない
[3 + 4]
=> aBlock

"ブロックは入れ子にできる
[[1] value] value
=> 1

"内側のブロックを値として返す
[[1]] value value
=> 1

"--- 引数を 1 つ取るブロック ---

[:x | x * 2] value: 3
=> 6

"引数は本体の中で識別子として解決できる（§4 の裸の識別子と違う点）
[:each | each + 1] value: 10
=> 11

"--- 引数を 2 つ取るブロック ---

[:x :y | x + y] value: 3 value: 4
=> 7

"value:value: は 1 回の送信で、セレクタは value:value:（§3.4）
[:x :y | x - y] value: 10 value: 4
=> 6

"--- 引数の数の上限 ---

"引数は 0〜2 個（要件 F-2-5）。3 個は構文エラー
[:x :y :z | x] value: 1 value: 2 value: 3
=> #Syntax

"--- 引数の数が合わない ---

[:x | x] value
=> #TypeError

[3] value: 1
=> #TypeError

[:x :y | x] value: 1
=> #TypeError

"--- セル参照との組み合わせ ---

!pending m3
!A1 := 3
[:x | x + A1] value: 1
=> 4

!pending m3
!A1 := 3
[A1 * 2] value
=> 6

"--- 数式のブロックの本体は式ちょうど 1 つ ---

"数式は副作用を持てない（要件 F-2-10）。ブロックの中でも代入は拒否する
[:x | | t | t := x. t] value: 1
=> #Syntax

"代入できない以上、一時変数の宣言だけを書いても意味がない
[| t | 1] value
=> #Syntax

"文の区切りも数式には現れない（§3.1）
[1. 2] value
=> #Syntax

"^ による返却も同じ
[^ 1] value
=> #Syntax

"--- 構文エラー ---

"閉じていない角括弧
[1
=> #Syntax

"引数の区切り | が無い
[:x x] value: 1
=> #Syntax

"本体が空のブロックも、式がちょうど 1 つという規則から外れる
"（§3.8 の「空の丸括弧は式ではない」と揃えている）
[]
=> #Syntax

"--- 名前は影にできない（§5.1、§7.5 と同じ規則） ---

"入れ子のブロックが外側の引数と同じ名前を宣言できない。
"影になった名前は読み手が追えないため、開始記号によらず #Syntax とする
[:x | [:x | x] value: 1] value: 2
=> #Syntax

"同じ並びに同じ名前を 2 つ書くのも宣言の重複
[:x :x | x] value: 1 value: 2
=> #Syntax

"外側と違う名前なら入れ子にできる
[:x | [:y | x + y] value: 1] value: 2
=> 3
