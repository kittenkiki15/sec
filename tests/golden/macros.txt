"言語仕様書 §7（マクロ）に対応するゴールデンテスト。
"代入そのものは assignment.txt に分けてある。
"
"マクロのケースは最初の行に !macro を置く（ADR-0018）。無いケースは数式として読む。
"数式とマクロは開始記号が違うので、同じ原文でも結果が変わる。

"--- マクロの宣言（§7.1） ---

"宣言部を持つマクロは、!macro に起動するメッセージを添えて評価する（ADR-0018）
!macro monthlyTotal
monthlyTotal
    | total |
    total := 3.
    ^ total
=> 3

"キーワードパターンは引数を取る。引数は本体の中で識別子として読める
!macro from: 1 to: 3
from: start to: end
    ^ start + end
=> 4

"引数はセルへの書き込みにも使える
!macro summarize: 'Q1'
summarize: label
    A14 := label.
    ^ A14
=> 'Q1'

"引数への代入は書けない。書き換えたければ一時変数を宣言して写す（§7.3）
!macro double: 2
double: n
    n := n * 2.
    ^ n
=> #Syntax

"二項セレクタのパターンは認めない。マクロの名前に記号は使わない
!macro + 1
+ other
    ^ other
=> #Syntax

"宣言部だけで本体が無いものは書けない（§7.2）
!macro monthlyTotal
monthlyTotal
=> #Syntax

"パターンと違うセレクタを送れば理解しない
!macro yearlyTotal
monthlyTotal
    ^ 1
=> #DoesNotUnderstand

"--- 本体は文の列 ---

"^ で値を返す
!macro
^ 3
=> 3

"同じ原文を数式として読めば構文エラー（§3.1、要件 F-2-10）
^ 3
=> #Syntax

"文は . で区切る
!macro
1 + 1.
^ 2 + 2
=> 4

"末尾の . は書いてよい
!macro
^ 3.
=> 3

"文が空になる区切りは書けない
!macro
1 + 1. . ^ 2
=> #Syntax

"^ が無ければ nil を返す。マクロは値を返すために書くとは限らない
!macro
1 + 1
=> nil

"^ は文の列の最後にだけ書ける。後ろに文は続けられない
!macro
^ 1.
2 + 2
=> #Syntax

"--- 一時変数 ---

!macro
| a |
a := 3.
^ a + 1
=> 4

"宣言しただけの一時変数は nil
!macro
| a |
^ a
=> nil

"名前は 1 つの宣言に並べる
!macro
| a b |
a := 3.
b := 4.
^ a + b
=> 7

"何も宣言しない形も書ける
!macro
| |
^ 1
=> 1

"宣言は本体の先頭にだけ置ける
!macro
| a |
a := 1.
| b |
^ a
=> #Syntax

"宣言を 2 つに分けられない
!macro
| a |
| b |
^ 1
=> #Syntax

"同じ名前を二重に宣言できない
!macro
| a a |
^ 1
=> #Syntax

"宣言だけで文が無い本体は書けない（§5.1 の [] と揃えている）
!macro
| a |
=> #Syntax

"--- マクロのブロック ---

"ブロックの本体は文の列と一時変数を持てる（要件 F-2-5）。数式のブロックとの違い
!macro
^ [:x | | t | t := x * 2. t + 1] value: 3
=> 7

"ブロックの値は最後の文の値
!macro
^ [1. 2. 3] value
=> 3

"最後の文が代入ならブロックの値は nil。代入は値を持たない文（§7.2）
!macro
| a |
^ [a := 1] value
=> nil

"ブロックは外側の一時変数を読み書きできる
!macro
| a |
a := 1.
[a := a + 1] value.
^ a
=> 2

"外側と同じ名前を内側で宣言することはできない
!macro
| a |
^ [| a | a] value
=> #Syntax

"ブロック引数と同じ名前の一時変数も宣言できない
!macro
^ [:x | | x | x] value: 1
=> #Syntax

"--- 非局所リターン ---

"ブロックの中の ^ はマクロ全体を終える
!macro
#(1 2 3) do: [:e | e > 1 ifTrue: [^ e]].
^ 0
=> 2

"^ に達しなければ、そのまま次の文へ進む
!macro
#(1 2 3) do: [:e | e > 9 ifTrue: [^ e]].
^ 0
=> 0

"ブロックの中でも ^ は文の列の最後にだけ書ける
!macro
^ [^ 1. 2] value
=> #Syntax

"--- 繰り返し: do: ---

"do: は受け手を返す。集めるのは collect:（§6.3）
!macro
^ #(1 2 3) do: [:e | e]
=> #(1 2 3)

"要素を順に渡す
!macro
| sum |
sum := 0.
#(1 2 3) do: [:e | sum := sum + e].
^ sum
=> 6

"範囲の列挙は Cell を渡す（ADR-0015）
!macro
!A1 := 1
!A2 := 2
| sum |
sum := 0.
(A1 to: A2) do: [:c | sum := sum + c value].
^ sum
=> 3

"区間も列挙できる（ADR-0016）
!macro
| sum |
sum := 0.
(1 to: 4) do: [:e | sum := sum + e].
^ sum
=> 10

"空を列挙してもブロックは評価されない
!macro
| n |
n := 0.
#() do: [:e | n := n + 1].
^ n
=> 0

"引数を取らないブロックは #TypeError（§5.1 の value の規則と同じ）
!macro
^ #(1 2) do: [1]
=> #TypeError

"セレクタの理解は文脈に依らない。数式から送っても構文エラーにはならない。
"ただし数式は副作用を持てないので、受け手が返るだけで何も観測できない（§6.4）
#(1 2 3) do: [:e | e]
=> #(1 2 3)

"--- 繰り返し: whileTrue: ---

!macro
| i |
i := 0.
[i < 3] whileTrue: [i := i + 1].
^ i
=> 3

"最初から偽なら本体は 1 度も評価されない
!macro
| n |
n := 0.
[false] whileTrue: [n := n + 1].
^ n
=> 0

"whileTrue: は nil を返す。値を作るための繰り返しではない
!macro
| i |
i := 0.
^ [i < 1] whileTrue: [i := i + 1]
=> nil

"受け手のブロックが真偽値を返さなければ #TypeError
!macro
^ [1] whileTrue: [2]
=> #TypeError

"受け手がブロックでなければ理解しない
!macro
^ true whileTrue: [1]
=> #DoesNotUnderstand

"引数がブロックでなければ #TypeError（条件式と同じ理由、§5.2）
!macro
| i |
i := 0.
^ [i < 1] whileTrue: 1
=> #TypeError

"--- 実行上限（要件 N-5 / F-3-5） ---

"止まらないマクロは上限で中断する
!macro
| i |
i := 0.
[true] whileTrue: [i := i + 1].
^ i
=> #Timeout

"上限は数式にも当たる。代入が書けなくても、停止しない繰り返しは数式で書ける
[true] whileTrue: [1]
=> #Timeout
