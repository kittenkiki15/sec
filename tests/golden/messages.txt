"言語仕様書 §3（メッセージ式）に対応するゴールデンテスト。
"優先順位そのものは precedence.txt に分けてある。

"--- 単項メッセージ ---

5 abs
=> 5

-5 abs
=> 5

"単項メッセージは左から右へ連ねて送れる
3 negated abs
=> 3

2 squared squared
=> 16

"--- 二項メッセージ ---

3 + 4
=> 7

2 * 3
=> 6

10 - 4
=> 6

"比較も二項メッセージで、真偽値を返す
3 > 5
=> false

3 = 3
=> true

"--- キーワードメッセージ ---

3 max: 4
=> 4

3 min: 4
=> 3

"キーワードが複数あっても、連結した 1 つのセレクタ between:and: への送信になる
3 between: 1 and: 5
=> true

7 between: 1 and: 5
=> false

"max: と min: は連結されて max:min: になる。そのようなセレクタは無い
3 max: 4 min: 2
=> #DoesNotUnderstand

"括弧で区切れば 2 つのメッセージになる
(3 max: 4) min: 2
=> 2

"--- 理解できないメッセージ ---

3 foo
=> #DoesNotUnderstand

3 foo: 4
=> #DoesNotUnderstand

"--- 構文エラー ---

"二項セレクタに右の項が無い
3 +
=> #Syntax

"二項セレクタに受け手が無い
+ 3
=> #Syntax

"キーワードに引数が無い
3 max:
=> #Syntax

"キーワードに受け手が無い
max: 3
=> #Syntax

"閉じていない丸括弧
(3 + 4
=> #Syntax

"空の丸括弧は式ではない
()
=> #Syntax

"--- 数式に副作用の構文は書けない（§3.1、要件 F-2-10） ---
"文法そのものは §7 で定める。ここでは数式が拒否することだけを固定する。

"文の列
3 + 4. 5
=> #Syntax

"代入
a := 3
=> #Syntax

"返却
^ 3
=> #Syntax
