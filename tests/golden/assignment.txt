"言語仕様書 §7.2 / §7.3（代入とセルへの代入）に対応するゴールデンテスト。
"文の列・一時変数・繰り返しは macros.txt に分けてある。
"
"数式として書いたときに構文エラーになることを、この中で対にして固定している。
"これが数式とマクロの境界（要件 F-2-10、ADR-0007 D-3）。

"--- 一時変数への代入 ---

!macro
| a |
a := 3.
^ a
=> 3

"空白の無い a:=1 も代入。キーワード a: と二項の = には切らない（§1.4）
!macro
| a |
a:=3.
^ a
=> 3

"代入は上書きする。右辺は代入前の値を読む
!macro
| a |
a := 3.
a := a + 1.
^ a
=> 4

"代入の右辺は式ならなんでもよい
!macro
!A1 := 2
| a |
a := A1 squared.
^ a
=> 4

"宣言の無い識別子への代入は構文エラー。宣言の書き忘れを静的に捕まえる
!macro
a := 1.
^ 1
=> #Syntax

"宣言の無い識別子を読むのは #Ref（§4.2。名前付き範囲が入れば解決できるようになる）
!macro
^ total
=> #Ref

"--- 一時変数にセルを代入する（ADR-0028） ---

"一時変数はセルをセルのまま持つ。代入の時点では値を読まないので、値がエラーでも終わらない
!macro
!A1 := =1 / 0
| a |
a := A1.
^ 3
=> 3

"値を読むのは使ったとき。理解しないメッセージは保持する値へ委譲される（§4.2）
!macro
!A1 := =1 / 0
| a |
a := A1.
^ a + 1
=> #DivideByZero

"値を持たせたいときは value を送る。値がエラーなら代入の右辺がエラーなので、そこで終わる
!macro
!A1 := =1 / 0
| a |
a := A1 value.
^ 3
=> #DivideByZero

"セルのまま持てば、後の書き込みを読む
!macro
!A1 := 1
| a |
a := A1.
A1 := 5.
^ a
=> 5

"value で読んだ値は、後の書き込みで変わらない
!macro
!A1 := 1
| a |
a := A1 value.
A1 := 5.
^ a
=> 1

"数式のセルも同じ。セルのまま持てば、書き込みが下流に届いた後の値を読む
!macro
!A1 := 1
!B1 := =A1 + 1
| b |
b := B1.
A1 := 5.
^ b
=> 6

"--- 代入は文であって式ではない ---

"式の中に代入は現れない
!macro
| a |
^ 3 + (a := 1)
=> #Syntax

"連鎖代入も書けない
!macro
| a b |
a := b := 3.
^ a
=> #Syntax

"キーワードメッセージの引数にも書けない
!macro
| a |
^ 3 max: (a := 5)
=> #Syntax

"--- セルへの代入（ADR-0007 D-3） ---

!macro
A1 := 3.
^ A1
=> 3

"右辺は式でよい
!macro
!A1 := 1
!A2 := 2
B1 := (A1 to: A2) sum.
^ B1
=> 3

"書き込んだ値は同じマクロの中で読み直せる
!macro
A1 := 1.
A1 := A1 + 1.
^ A1
=> 2

"左辺のセル参照は読まれない。書き込み先を指すだけなので、元の値がエラーでも通る
!macro
!A1 := =1 / 0
A1 := 3.
^ A1
=> 3

"数式の入っていたセルは値で置き換わる。B1 は A1 を追わなくなる
!macro
!A1 := 1
!B1 := =A1 + 1
B1 := 10.
A1 := 5.
^ B1
=> 10

"右辺がエラーならセルは書き換わらず、マクロはそのエラーで終わる（要件 F-3-4）
!macro
!A1 := 1
A1 := 1 / 0.
^ A1
=> #DivideByZero

"--- 書き込んだ値の置き方（ADR-0027） ---

"文字列は文字列のまま書き込まれる。数に見える文字列も数にならない
!macro
A1 := '3'.
^ A1
=> '3'

"= で始まる文字列も数式にならない
!macro
!B1 := 1
A1 := '=B1'.
^ A1
=> '=B1'

"引用符を含む文字列も戻る
!macro
A1 := 'it''s'.
^ A1
=> 'it''s'

"小数は同じ値に戻る。表記で丸めない
!macro
A1 := 2 sqrt.
^ A1 = 2 sqrt
=> true

"配列もリテラルとして書き込める
!macro
A1 := #(1 'a' #b nil).
^ A1
=> #(1 'a' #b nil)

"エラーを要素に持つ配列は書き込めない。そのエラーでマクロが終わる。
"表記の #(#Overflow) はシンボルの配列として読み戻され、別の値になってしまう
!macro
A1 := #(1 1.0e400).
^ A1
=> #Overflow

"セルを右辺にすると、書き込まれるのはセルではなく値。書いた後は元のセルを追わない
!macro
!B1 := 2
!C1 := =B1 * 3
A1 := C1.
B1 := 10.
^ A1
=> 6

"配列の要素の Cell も値まで解決する。範囲の列挙が渡すのは Cell なので（§6.3）、
"collect: の結果は Cell の配列になる。書いた後は元のセルを追わない
!macro
!B1 := 1
!B2 := 2
A1 := (B1 to: B2) collect: [:c | c].
B1 := 10.
^ A1
=> #(1 2)

"要素の Cell の値がエラーなら書き込めない。そのエラーでマクロが終わる
!macro
!B1 := =1 / 0
A1 := (B1 to: B1) collect: [:c | c].
^ 3
=> #DivideByZero

"要素にもリテラルで書けない値は置けない。ブロックを要素に持つ配列
!macro
A1 := #(1) collect: [:x | [x]].
^ A1
=> #TypeError

"真偽値
!macro
A1 := 3 > 2.
^ A1
=> true

"シンボル。引用符の要る綴りも戻る
!macro
A1 := #'a b'.
^ A1
=> #'a b'

"負の小数も戻る
!macro
A1 := 0 - 1.5e-300.
^ A1
=> -1.5e-300

"nil はセルを空にする（ADR-0010）。数式から見ても空のセルになる
!macro
!A1 := 1
!B1 := =A1 isNil
A1 := nil.
^ B1
=> true

"書き込み先を解決できなければ #Ref（§4.2、ADR-0020）。行 0 のセルは存在しない
!macro
A0 := 3.
^ 1
=> #Ref

"リテラルで書けない値は書き込めない。ブロック
!macro
A1 := [1].
^ A1
=> #TypeError

"範囲
!macro
!B1 := 1
A1 := B1 to: B1.
^ A1
=> #TypeError

"区間
!macro
A1 := 1 to: 3.
^ A1
=> #TypeError

"--- 書き込みは同じマクロの中で下流に届く（ADR-0027） ---

"数式セルを読めば、それまでの書き込みを反映した値になる
!macro
!A1 := 1
!B1 := =A1 + 1
A1 := 5.
^ B1
=> 6

"鎖の先まで届く
!macro
!A1 := 1
!B1 := =A1 + 1
!C1 := =B1 * 2
A1 := 5.
^ C1
=> 12

"範囲を通した依存にも届く
!macro
!A1 := 1
!A2 := 2
!B1 := =(A1 to: A2) sum
A2 := 10.
^ B1
=> 11

"巡っている数式の片方に値を書くと循環が解ける
!macro
!B1 := =C1
!C1 := =B1
B1 := 1.
^ C1
=> 1

"範囲への代入は本書では定めない（§7.8、未決論点 D-4）
!macro
A1:B2 := 0.
^ A1
=> #Syntax

"代入の左辺になれるのは一時変数とセル参照だけ
!macro
3 := 1.
^ 3
=> #Syntax

"--- 数式に代入は書けない（要件 F-2-10） ---

"一時変数への代入
a := 3
=> #Syntax

"セルへの代入。マクロでのみ許す（ADR-0007 D-3）
A1 := 3
=> #Syntax

"セルに入れた数式の中でも同じ。B1 に書き込む数式は作れない
!A1 := =B1 := 3
A1
=> #Syntax

"一時変数の宣言も数式には現れない
| a |
a
=> #Syntax

"文の列も同じ（§3.1）
A1 := 1. A1
=> #Syntax

"ブロックの中でも同じ（§5.1）
[:x | x := 1] value: 2
=> #Syntax
