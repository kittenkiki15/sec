"言語仕様書 §7.2 / §7.3（代入とセルへの代入）に対応するゴールデンテスト。
"文の列・一時変数・繰り返しは macros.txt に分けてある。
"
"数式として書いたときに構文エラーになることを、この中で対にして固定している。
"これが数式とマクロの境界（要件 F-2-10、ADR-0007 D-3）。

"--- 一時変数への代入 ---

!macro
| a |
a := 3.
^ a
=> 3

"代入は上書きする。右辺は代入前の値を読む
!macro
| a |
a := 3.
a := a + 1.
^ a
=> 4

"代入の右辺は式ならなんでもよい
!macro
!A1 := 2
| a |
a := A1 squared.
^ a
=> 4

"宣言の無い識別子への代入は構文エラー。宣言の書き忘れを静的に捕まえる
!macro
a := 1.
^ 1
=> #Syntax

"宣言の無い識別子を読むのは #Ref（§4.2。名前付き範囲が入れば解決できるようになる）
!macro
^ total
=> #Ref

"--- 代入は文であって式ではない ---

"式の中に代入は現れない
!macro
| a |
^ 3 + (a := 1)
=> #Syntax

"連鎖代入も書けない
!macro
| a b |
a := b := 3.
^ a
=> #Syntax

"キーワードメッセージの引数にも書けない
!macro
| a |
^ 3 max: (a := 5)
=> #Syntax

"--- セルへの代入（ADR-0007 D-3） ---

!macro
A1 := 3.
^ A1
=> 3

"右辺は式でよい
!macro
!A1 := 1
!A2 := 2
B1 := (A1 to: A2) sum.
^ B1
=> 3

"書き込んだ値は同じマクロの中で読み直せる
!macro
A1 := 1.
A1 := A1 + 1.
^ A1
=> 2

"左辺のセル参照は読まれない。書き込み先を指すだけなので、元の値がエラーでも通る
!macro
!A1 := =1 / 0
A1 := 3.
^ A1
=> 3

"数式の入っていたセルは値で置き換わる。B1 は A1 を追わなくなる
!macro
!A1 := 1
!B1 := =A1 + 1
B1 := 10.
A1 := 5.
^ B1
=> 10

"右辺がエラーならセルは書き換わらず、マクロはそのエラーで終わる（要件 F-3-4）
!macro
!A1 := 1
A1 := 1 / 0.
^ A1
=> #DivideByZero

"範囲への代入は本書では定めない（§7.8、未決論点 D-4）
!macro
A1:B2 := 0.
^ A1
=> #Syntax

"代入の左辺になれるのは一時変数とセル参照だけ
!macro
3 := 1.
^ 3
=> #Syntax

"--- 数式に代入は書けない（要件 F-2-10） ---

"一時変数への代入
a := 3
=> #Syntax

"セルへの代入。マクロでのみ許す（ADR-0007 D-3）
A1 := 3
=> #Syntax

"セルに入れた数式の中でも同じ。B1 に書き込む数式は作れない
!A1 := =B1 := 3
A1
=> #Syntax

"一時変数の宣言も数式には現れない
| a |
a
=> #Syntax

"文の列も同じ（§3.1）
A1 := 1. A1
=> #Syntax

"ブロックの中でも同じ（§5.1）
[:x | x := 1] value: 2
=> #Syntax
