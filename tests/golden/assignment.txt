"言語仕様書 §7.2 / §7.3（代入とセルへの代入）に対応するゴールデンテスト。
"文の列・一時変数・繰り返しは macros.txt に分けてある。
"
"数式として書いたときに構文エラーになることを、この中で対にして固定している。
"これが数式とマクロの境界（要件 F-2-10、ADR-0007 D-3）。

"--- 一時変数への代入 ---

!macro
!pending m4
| a |
a := 3.
^ a
=> 3

"空白の無い a:=1 も代入。キーワード a: と二項の = には切らない（§1.4）
!macro
!pending m4
| a |
a:=3.
^ a
=> 3

"代入は上書きする。右辺は代入前の値を読む
!macro
!pending m4
| a |
a := 3.
a := a + 1.
^ a
=> 4

"代入の右辺は式ならなんでもよい
!macro
!pending m4
!A1 := 2
| a |
a := A1 squared.
^ a
=> 4

"宣言の無い識別子への代入は構文エラー。宣言の書き忘れを静的に捕まえる
!macro
!pending m4
a := 1.
^ 1
=> #Syntax

"宣言の無い識別子を読むのは #Ref（§4.2。名前付き範囲が入れば解決できるようになる）
!macro
!pending m4
^ total
=> #Ref

"--- 代入は文であって式ではない ---

"式の中に代入は現れない
!macro
!pending m4
| a |
^ 3 + (a := 1)
=> #Syntax

"連鎖代入も書けない
!macro
!pending m4
| a b |
a := b := 3.
^ a
=> #Syntax

"キーワードメッセージの引数にも書けない
!macro
!pending m4
| a |
^ 3 max: (a := 5)
=> #Syntax

"--- セルへの代入（ADR-0007 D-3） ---

!macro
!pending m4
A1 := 3.
^ A1
=> 3

"右辺は式でよい
!macro
!pending m4
!A1 := 1
!A2 := 2
B1 := (A1 to: A2) sum.
^ B1
=> 3

"書き込んだ値は同じマクロの中で読み直せる
!macro
!pending m4
A1 := 1.
A1 := A1 + 1.
^ A1
=> 2

"左辺のセル参照は読まれない。書き込み先を指すだけなので、元の値がエラーでも通る
!macro
!pending m4
!A1 := =1 / 0
A1 := 3.
^ A1
=> 3

"数式の入っていたセルは値で置き換わる。B1 は A1 を追わなくなる
!macro
!pending m4
!A1 := 1
!B1 := =A1 + 1
B1 := 10.
A1 := 5.
^ B1
=> 10

"右辺がエラーならセルは書き換わらず、マクロはそのエラーで終わる（要件 F-3-4）
!macro
!pending m4
!A1 := 1
A1 := 1 / 0.
^ A1
=> #DivideByZero

"--- 書き込んだ値の置き方（ADR-0027） ---

"文字列は文字列のまま書き込まれる。数に見える文字列も数にならない
!macro
!pending m4
A1 := '3'.
^ A1
=> '3'

"= で始まる文字列も数式にならない
!macro
!pending m4
!B1 := 1
A1 := '=B1'.
^ A1
=> '=B1'

"引用符を含む文字列も戻る
!macro
!pending m4
A1 := 'it''s'.
^ A1
=> 'it''s'

"小数は同じ値に戻る。表記で丸めない
!macro
!pending m4
A1 := 2 sqrt.
^ A1 = 2 sqrt
=> true

"配列もリテラルとして書き込める
!macro
!pending m4
A1 := #(1 'a' #b nil).
^ A1
=> #(1 'a' #b nil)

"セルを右辺にすると、書き込まれるのはセルではなく値。書いた後は元のセルを追わない
!macro
!pending m4
!B1 := 2
!C1 := =B1 * 3
A1 := C1.
B1 := 10.
^ A1
=> 6

"リテラルで書けない値は書き込めない。ブロック
!macro
!pending m4
A1 := [1].
^ A1
=> #TypeError

"範囲
!macro
!pending m4
!B1 := 1
A1 := B1 to: B1.
^ A1
=> #TypeError

"区間
!macro
!pending m4
A1 := 1 to: 3.
^ A1
=> #TypeError

"--- 書き込みは同じマクロの中で下流に届く（ADR-0027） ---

"数式セルを読めば、それまでの書き込みを反映した値になる
!macro
!pending m4
!A1 := 1
!B1 := =A1 + 1
A1 := 5.
^ B1
=> 6

"鎖の先まで届く
!macro
!pending m4
!A1 := 1
!B1 := =A1 + 1
!C1 := =B1 * 2
A1 := 5.
^ C1
=> 12

"範囲を通した依存にも届く
!macro
!pending m4
!A1 := 1
!A2 := 2
!B1 := =(A1 to: A2) sum
A2 := 10.
^ B1
=> 11

"巡っている数式の片方に値を書くと循環が解ける
!macro
!pending m4
!B1 := =C1
!C1 := =B1
B1 := 1.
^ C1
=> 1

"範囲への代入は本書では定めない（§7.8、未決論点 D-4）
!macro
!pending m4
A1:B2 := 0.
^ A1
=> #Syntax

"代入の左辺になれるのは一時変数とセル参照だけ
!macro
!pending m4
3 := 1.
^ 3
=> #Syntax

"--- 数式に代入は書けない（要件 F-2-10） ---

"一時変数への代入
a := 3
=> #Syntax

"セルへの代入。マクロでのみ許す（ADR-0007 D-3）
A1 := 3
=> #Syntax

"セルに入れた数式の中でも同じ。B1 に書き込む数式は作れない
!A1 := =B1 := 3
A1
=> #Syntax

"一時変数の宣言も数式には現れない
| a |
a
=> #Syntax

"文の列も同じ（§3.1）
A1 := 1. A1
=> #Syntax

"ブロックの中でも同じ（§5.1）
[:x | x := 1] value: 2
=> #Syntax
