"数のセレクタ。仕様書 §6.1 に対応する。
"
"数は整数と小数の 2 種（ADR-0012）。整数は任意精度、小数は IEEE754 倍精度。
"割り切れる除算は整数を返す。
"
"範囲やコレクションの集計（sum など）は collections.txt にある。

"--- 加減乗 ---

3 + 4
=> 7

3 - 4
=> -1

3 * 4
=> 12

"整数どうしは整数のまま
2 * 3
=> 6

"整数と小数が混ざると小数になる
1 + 2.0
=> 3.0

2.5 * 2
=> 5.0

"--- 除算 ---

"割り切れれば整数を返す（ADR-0012）
6 / 3
=> 2

"割り切れなければ小数
7 / 2
=> 3.5

"片方が小数なら、割り切れても小数
6.0 / 3
=> 2.0

0 / 5
=> 0

"小数は倍精度なので、循環小数は途中で打ち切られる
1 / 3
=> 0.3333333333333333

1 / 0
=> #DivideByZero

1.0 / 0
=> #DivideByZero

1 / 0.0
=> #DivideByZero

0 / 0
=> #DivideByZero

"--- 商と剰余 ---

"// は床除算。商は負の無限大の側へ丸める（Smalltalk-80）
7 // 2
=> 3

-7 // 2
=> -4

7 // -2
=> -4

"剰余の符号は除数に合わせる。self = (self // n) * n + (self \\ n) が常に成り立つ
7 \\ 2
=> 1

-7 \\ 2
=> 1

7 \\ -2
=> -1

"受け手が小数でも、商は整数
7.5 // 2
=> 3

"剰余は小数になりうる
7.5 \\ 2
=> 1.5

7 // 0
=> #DivideByZero

7 \\ 0
=> #DivideByZero

"--- 単項 ---

5 abs
=> 5

-5 abs
=> 5

0 abs
=> 0

5 negated
=> -5

-5 negated
=> 5

3 squared
=> 9

-3 squared
=> 9

"平方根は常に小数。一般に無理数になるため（§6.1）
4 sqrt
=> 2.0

0 sqrt
=> 0.0

2 sqrt
=> 1.4142135623730951

"負の数の平方根は実数の範囲に無い
-1 sqrt
=> #TypeError

"--- 丸めと切り捨て ---

"どちらも整数を返す
3.7 rounded
=> 4

3.2 rounded
=> 3

"端数がちょうど半分なら大きい側へ（Smalltalk-80 の rounded）
2.5 rounded
=> 3

-2.5 rounded
=> -2

-3.7 rounded
=> -4

"truncated は 0 の側へ落とす
3.7 truncated
=> 3

-3.7 truncated
=> -3

"整数に送っても整数のまま
3 rounded
=> 3

3 truncated
=> 3

"--- 比較 ---

3 = 3
=> true

3 = 4
=> false

"整数と小数は、値が等しければ等しい
1 = 1.0
=> true

3 ~= 4
=> true

3 ~= 3
=> false

3 < 4
=> true

4 < 3
=> false

3 <= 3
=> true

3 > 4
=> false

3 >= 4
=> false

3 >= 3
=> true

"--- between:and: ---

3 between: 1 and: 5
=> true

"境界は含む
1 between: 1 and: 5
=> true

5 between: 1 and: 5
=> true

6 between: 1 and: 5
=> false

0 between: 1 and: 5
=> false

"逆向きの区間は常に false。範囲（§4.3）と違い、正規化しない
3 between: 5 and: 1
=> false

"--- min: と max: ---

3 max: 4
=> 4

3 min: 4
=> 3

-1 max: -5
=> -1

"等しければその値
3 max: 3
=> 3

"型が混ざっても比較できる
3 max: 3.5
=> 3.5

"--- 任意精度の整数（ADR-0012） ---

"倍精度小数では表せない桁も正確に扱う
9007199254740993 + 1
=> 9007199254740994

12345678901234567890 * 2
=> 24691357802469135780

"小数は倍精度なので、丸め誤差はそのまま現れる
0.1 + 0.2
=> 0.30000000000000004

"--- 型の誤り ---

"受け手はセレクタを理解するが、引数の型が合わない
1 + 'abc'
=> #TypeError

1 + nil
=> #TypeError

1 + true
=> #TypeError

1 < 'abc'
=> #TypeError

1 max: nil
=> #TypeError

"受け手がそのセレクタを理解しない場合は #DoesNotUnderstand（§6.0）
'abc' + 1
=> #DoesNotUnderstand

3 foo
=> #DoesNotUnderstand

"= と ~= は型が違っても誤りにならない。等しくないだけ
1 = 'abc'
=> false

1 = nil
=> false

1 ~= 'abc'
=> true
