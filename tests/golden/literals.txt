"言語仕様書 §1（字句）と §2（リテラル）に対応するゴールデンテスト。
"値の表記は仕様書 §0.3 に従う。エラーは種別シンボルだけを期待値に書く。

"--- 整数 ---

42
=> 42

0
=> 0

"先頭の 0 は無視する。桁揃えのために 007 と書けると都合が良い
007
=> 7

"--- 小数 ---

3.14
=> 3.14

0.5
=> 0.5

"小数点の両側に数字が要る。.5 は小数ではない
.5
=> #Syntax

"5. はマクロの文区切り（§7）と紛れるため、小数としては認めない
5.
=> #Syntax

"--- 指数 ---

"指数は仮数の種別を変えない。整数の仮数に非負の指数なら整数のまま
1e3
=> 1000

1.5e3
=> 1500.0

"指数が負なら小数になる
2e-3
=> 0.002

"指数の e は小文字だけ。E3 はセル参照の形（ADR-0007 D-2）なので 1E3 は式にならない
1E3
=> #Syntax

"--- 負のリテラルと二項の - ---

-5
=> -5

"単項メッセージの受け手は負のリテラルそのもの
-5 abs
=> 5

"直前が一次式の終端なら - は二項セレクタ。空白の有無で意味を変えない
3 -4
=> -1

"直前が二項セレクタなら - は負のリテラルの一部
3 + -4
=> -1

3 - -4
=> 7

"空白の有無で意味を変えない。3 -4 と 3 - 4 と 3-4 はすべて -1（§2.1）
3 - 4
=> -1

3-4
=> -1

") も一次式の終端なので、その後の - は二項セレクタ（§2.1）
(1 + 2) -3
=> 0

"基数表記（Smalltalk の 16rFF）は本仕様に含めない。16 に rFF を送る式になる（§2.1）
16rFF
=> #DoesNotUnderstand

"--- 文字列 ---

'hello'
=> 'hello'

''
=> ''

"文字列の中の ' は二重にして書く
'It''s'
=> 'It''s'

"文字列は改行を跨げる
'ab
cd'
=> 'ab
cd'

"閉じていない文字列は構文エラー
'abc
=> #Syntax

"円記号などによるエスケープは無い。\n は 2 文字の文字列（§2.2）
'\n'
=> '\n'

"--- シンボル ---

#foo
=> #foo

"キーワードセレクタのシンボル
#at:put:
=> #at:put:

"二項セレクタのシンボル
#+
=> #+

"識別子にできない綴りは引用符で囲む
#'hello world'
=> #'hello world'

"# の後ろは綴りとして読むので、セル参照の形もシンボルになる（§2.3）
#A1
=> #A1

"--- 真偽値と nil ---

true
=> true

false
=> false

nil
=> nil

"--- リテラル配列 ---

#(1 2 3)
=> #(1 2 3)

#()
=> #()

#(1 'two' #three true nil)
=> #(1 'two' #three true nil)

"リテラル配列の中では裸の識別子はシンボルになる
#(foo bar)
=> #(#foo #bar)

"入れ子のリテラル配列は # を省ける
#(1 (2 3))
=> #(1 #(2 3))

"入れ子に # を付けても同じ（§2.4）
#(1 #(2 3))
=> #(1 #(2 3))

"裸のキーワードセレクタもシンボルになる（§2.4）
#(at:put:)
=> #(#at:put:)

"要素はリテラルだけで、式は書けない。+ はシンボルになる
#(1 + 2)
=> #(1 #+ 2)

"要素の間の空白は、隣接するとトークンが変わる場合にだけ必要
#(1'foo')
=> #(1 'foo')

"空白が無いと 1 つのトークンになる
#(12)
=> #(12)

"配列の中の - は直前が一次式の終端なので二項セレクタ。裸のシンボルになる
#(1-2)
=> #(1 #- 2)

"閉じていないリテラル配列は構文エラー
#(1 2
=> #Syntax

"--- 空白とコメント ---

"空白の量は意味を持たない
3+4
=> 7

3   +   4
=> 7

"改行は空白と同じ扱いで、式は何行に跨っても良い（§1.1）
3
  +
  4
=> 7

"タブも空白として扱う（§1.1）
3	+	4
=> 7

"非 ASCII 文字は識別子に使えない（§1.2）
3 + あ
=> #Syntax

"キーワードの識別子と : の間に空白を置けない（§1.4）
3 max : 4
=> #Syntax

"コメントは空白と同じ扱いで、式の途中に置ける
3 "ここはコメント" + 4
=> 7

"コメントは改行を跨げる
3 + "ここで
改行しても良い" 4
=> 7

"コメントの中の " は二重にして書く
3 + "引用符は "" と書く" 4
=> 7

"閉じていないコメントは構文エラー
3 + 4 "閉じていない
=> #Syntax

"--- 二項セレクタの長さ（§1.4） ---

"2 文字の二項セレクタは受理する
3 >= 3
=> true

"3 文字以上は認めない。最長一致で切り出すため +++ は ++ と + に切れ、
"++ の右に項が無いので構文エラーになる
1 +++ 2
=> #Syntax

"=== も同様に == と = に切れる
1 === 1
=> #Syntax

"4 文字でも同じ
1 <==> 2
=> #Syntax
